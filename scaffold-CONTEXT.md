# T3 Docker Scaffold

A reusable template repository providing a Dockerized local dev environment for T3-stack projects (Next.js, tRPC, Drizzle, Postgres). It is not itself a product — it exists to be cloned via GitHub's template mechanism as the starting point for new apps.

## Language

**Scaffold**:
This repository itself — the template providing the dev environment, conventions, and starting structure for future projects. Not a deployable product.
_Avoid_: Project, template (reserve "template" for the GitHub distribution mechanism)

**Downstream project**:
A repository created by using the scaffold as a GitHub template. Where scaffold conventions get personalized into a real, shippable app.
_Avoid_: Child project, instance, clone

**Stock example**:
The default tRPC + Drizzle + UI example generated by the official `create-t3-app` CLI, deliberately kept as-is rather than replaced or deleted, so the scaffold proves a working end-to-end wiring out of the box.
_Avoid_: Demo, sample, boilerplate example
